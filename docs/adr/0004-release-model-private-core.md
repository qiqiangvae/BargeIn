# 核心代码暂不公开，公开仓库只放 App 与文档

**状态**：已由 [ADR-0005](0005-open-source.md) 取代（0.4.1 起源码并入公开仓库）。

v0.1 的发布计划是 MIT 开源：仓库整体公开、功能全开、将来卖预设。当前决定改为：**本仓库是开发仓库，不对外发布；对外发布走另一个公开仓库，只放 App 下载、文档与 issue；核心代码暂不公开，计划在稳定后开源。**

**为什么**

- 产品的复杂度集中在呈现与调度，公开核心代码等于把实现直接送出去。
- 先发布 App 与文档，用户仍然能判断它做什么、不做什么、联网边界在哪；透明不依赖源码。
- 承诺以后开源，是给用户的信任预期，不是当下的获客手段。

**允许**：公开 App 安装包、公开文档、公开 issue 与更新记录；以后按开源计划公开代码。

**不允许**：在公开仓库出现核心源码；用"开源"当现在的卖点；用付费内容锁功能。

**代价**

- 失去开源产品的传播与信任红利；获客更依赖口碑与文档。
- "以后开源"是没有日期的承诺，兑现不了会伤信任。
- README 不再宣称 MIT / 代码全公开；授权方式在公开发布时再确定。

**被否掉的方案**

- 继续 MIT 全开源：与"核心代码暂不公开"冲突。
- 只公开文档、连 App 也不发：没有真实用户信号。
