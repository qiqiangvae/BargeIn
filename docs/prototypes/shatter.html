这套呈现的约定

进入（自动）：0–0.36s 暗场（玻璃完整）→ 0.36s 一点破开（高光 ≤0.2s，冲击孔随后脱落）→ 0.36–2.0s 裂纹从炸点慢慢爬出去、越爬越快（每条裂口自身也是先慢后快），级联裂口跟着出现 → 约 0.9s / 1.4s 先掉一两块小碎片 → 2.25s 面板出现，画面停在"裂而未落"的状态等你处理。

退出（你点了才算）：喝了 / 推迟 / 中断任意一个动作后，面板先淡出，整片玻璃由近及远坠落（重力加速 + 自旋 + 横向漂移，约 2 秒），遮罩随碎片一起消失、露出桌面；落完窗口才关闭。

破碎怎么发生：炸点随机落在屏面偏上、不居中 → 先裂出 4–7 条带折线的主裂 → 每块楔形碎块再各自被随机裂口继续劈开（越靠近炸点裂得越碎），裂缝只终止在已有裂缝上，于是出现大量 T 形岔口与长短不一的局部弧。

音效：系统 Glass 一声，满音量，只在炸点响一次（实现上随炸点延后约 0.36s 播放）；跳过次数把等级推到 2 以上时，账本照旧把它换成重复的 alarm。原型不发声。

花纹：每次提醒重新生成一套（炸点、裂纹、碎片都随机），多屏按尺寸等比缩放共用；预览与到点也各自一套。减弱动态效果下不裂、不落、不闪，直接呈现静态裂痕，动作后立即关闭、不播坠落。

边界：档位取「大字墙 · 标准」——允许推迟、中断延迟 0s、等级上限 2；文案槽是标题 + 进度；画面不随账本升级加码。面板 2.25s 出现，交互解锁取「防误触 1s」与「面板出现 2.25s」的较大者；面板出现前 Esc / Enter 不响应。队列里的下一条等坠落播完再出现（约 2s）。评审可用 ?t=<毫秒> 冻结进入动画、?e=<毫秒> 冻结确认后的坠落。
